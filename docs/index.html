Virtual keyboard layout

Ten tabs. Thirty keys each.
Ten function keys for everything.

Tabs work like tmux sessions for your applications — one context per tab, each with a full set of thirty bindings. Function keys stay global, so F1 means the same thing everywhere.

⌨️

Function keys F1–F10

Global row, shared by every tab. Perfect for the ten apps you need no matter what you are doing.

🔢

Tab selectors 1–0

Ten named contexts — Dev, Work, Media, Games, Ops. Switch with a number key, the arrow keys, or a scroll of the wheel.

🔠

Letter & symbol keys Q–/

Thirty per-tab bindings across three rows: Q–P, A–; and Z–/. Spatial, deterministic, unforgettable.

Features

Deliberately restrained.
Relentlessly fast.

MaxLaunchpad does one thing: it makes your most-used applications instantly reachable from the keyboard. No plugin marketplace, no AI sidebar, no bloat.

⚡

Single-keystroke launch

The same key always launches the same app — forever. The window auto-hides the moment the program starts.

🌍

Global hotkey

Summon from any application with Alt + `. Modifiers and main key are re-bindable at runtime.

🖱️

Drag & drop setup

Drag an executable, shortcut or .app onto a key. Windows .lnk files are parsed for target, arguments and working directory automatically.

🔎

Quick Select

Search installed applications inside the edit dialog to auto-fill label, path and description — with ↑ ↓ Enter navigation.

🛠️

Arguments, working dir, admin

Every shortcut can carry command-line arguments, a working directory, a custom icon, a tooltip and Run as Admin on Windows.

🗂️

Multiple profiles

keyboard.yaml, work.yaml, gaming.yaml — switch with File ▸ New / Open / Save As.

💾

Auto-save with backups

Every change is written immediately, and the previous version is kept as a timestamped backup in backups/.

🖥️

Multi-monitor & Spaces

Appears on the display under your cursor and on the current macOS Space. Always on top, auto-hides on blur, locks to center.

🌗

Light, dark & custom CSS

Follow the system theme or force one. Drop a .css file into styles/ and make it entirely yours.

🧊

Compact mode

Hide the menu bar, button icons, button text, empty buttons or whole keyboard rows until only what you need remains.

🎨

Real icons, cached

Extracts icons from Windows UWP/Store apps and macOS .app bundles, supports custom paths and URLs, falls back to generated DiceBear avatars.

📥

Tray-first

The close button minimises to tray. Optional Launch on Startup and Start in Tray keep it out of your way.

Configuration

Plain YAML.
Version it. Sync it. Share it.

Everything lives in ~/.config/MaxLaunchpad/ on every platform (honouring XDG_CONFIG_HOME). Put that folder in a Git repo and your launcher follows you to every machine.

Quick start

Set up in 60 seconds.

  1. Launch it

    The virtual keyboard appears, and MaxLaunchpad settles into your system tray.

  2. Enable Drag & Drop Mode

    View ▸ Drag & Drop Mode keeps the window visible and movable while you configure.

  3. Drag apps onto keys

    From Explorer, Finder or Files — or right-click a key and use Quick Select.

  4. Name your tabs

    Right-click a number key 1–0 and choose Edit: Dev, Work, Media, Games.

  5. Press and go

    Turn Drag & Drop Mode off, hit Alt + ` anywhere, then one key. Done.

FAQ

Frequently asked questions

Is MaxLaunchpad free and open source?

Yes. MaxLaunchpad is an open-source Electron, React and TypeScript desktop app, free for personal and commercial use. There is no account, no cloud service and no telemetry.

Does it work on Windows 11?

Yes — Windows 10 and Windows 11 are both fully supported, and it works out of the box.

Does it run on Apple Silicon Macs?

Yes, on macOS 11 Big Sur or later with Apple Silicon. After installing, run xattr -cr /Applications/MaxLaunchpad.app to remove the quarantine attribute.

Does the global hotkey work on Linux / Wayland?

MaxLaunchpad targets Ubuntu 24.04 on Wayland. Because Wayland restricts global shortcut registration, you may need to bind the hotkey through GNOME’s own keyboard-shortcut settings.

Can I sync my launcher configuration between computers?

Yes. Everything lives in plain YAML under ~/.config/MaxLaunchpad/. Commit it to Git, sync it with Dropbox, OneDrive or Syncthing, or simply copy a single profile file to another machine.

How many shortcuts can I create?

310 per profile: ten function keys shared globally, plus ten tabs of thirty letter and symbol keys each. Create as many profiles as you like.

Can it launch Microsoft Store (UWP) apps, .lnk shortcuts or shell scripts?

Yes — .exe, .lnk, .bat, .cmd, .ps1, shell: targets and Store/UWP apps on Windows; .app bundles and shell scripts on macOS; ELF binaries, .desktop files, .sh, .py and .rb on Linux. URLs open in your default browser.

Can a shortcut pass command-line arguments or run as administrator?

Yes. Every shortcut supports arguments, a working directory, a custom icon, a tooltip description, and Run as Admin on Windows.

Is it a replacement for MaxLauncher?

It is a spiritual successor to the discontinued MaxLauncher, rebuilt from scratch with modern tooling and extended from Windows to macOS and Ubuntu. Profiles use MaxLaunchpad’s own YAML format.

Where are logs and backups stored?

~/.config/MaxLaunchpad/logs/ and ~/.config/MaxLaunchpad/backups/. A backup is written before each save whenever the profile content has changed.

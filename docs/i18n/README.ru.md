# MaxLaunchpad — кроссплатформенный лаунчер с управлением с клавиатуры

> Вызовите виртуальную клавиатуру сочетанием клавиш и нажмите одну клавишу, чтобы запустить приложение. Никакого ввода, поиска и лотереи нечёткого сопоставления.

MaxLaunchpad — бесплатный лаунчер приложений с открытым исходным кодом для Windows, macOS и Linux. Он назначает приложения на клавиши виртуальной клавиатуры, которая вызывается из любого приложения глобальной горячей клавишей, после чего достаточно одного нажатия, чтобы запустить нужную программу.

## Обзор возможностей

- **Детерминированный запуск** — одна и та же клавиша всегда запускает одно и то же приложение, порядок поиска ни на что не влияет.
- **310 сочетаний** — 10 вкладок по 30 клавиш плюс общие для всех вкладок клавиши `F1`–`F10`.
- **Глобальная горячая клавиша** — по умолчанию `Alt` + `` ` `` в Windows/Linux и `Option` + `` ` `` в macOS; полностью настраивается.
- **Запуск на любой платформе** — исполняемые файлы, ярлыки, скрипты, пакеты приложений, записи `.desktop`, URL, а также аргументы командной строки и рабочая папка.
- **Настройка перетаскиванием** — перетащите программу из Проводника, Finder или файлового менеджера на нужную клавишу.
- **Несколько профилей** — управляйте сценариями использования с помощью файлов `keyboard.yaml`, `work.yaml`, `gaming.yaml` и других.
- **Поиск и быстрый выбор** — найдите установленное приложение в диалоге редактирования, и название, путь и описание заполнятся автоматически.
- **Темы и интерфейс** — светлая, тёмная и системная темы, собственный CSS, компактный режим, режим «поверх всех окон» и автоматическое скрытие при потере фокуса.
- **Область уведомлений** — свёртывание в трей, автозапуск и запуск со скрытым окном.
- **Бесплатно и с открытым кодом** — на Electron, React и TypeScript: без учётной записи, без облака и без телеметрии.

## Установка

### Пакетные менеджеры

```shell
# Windows
winget install AwesomeDog.MaxLaunchpad

# macOS
brew install --cask AwesomeDog/tap/maxlaunchpad
```

### Прямая загрузка

Скачайте установщик для своей системы со [страницы выпусков](https://github.com/AwesomeDog/maxlaunchpad/releases).

| Платформа | Требование | Примечания |
| --- | --- | --- |
| Windows | Windows 10 или новее | Работает сразу после установки. |
| macOS | macOS 11 Big Sur или новее (Apple Silicon) | Выполните `xattr -cr /Applications/MaxLaunchpad.app`, чтобы снять атрибут карантина. |
| Linux | Ubuntu 24.04 или эквивалент | В Wayland глобальную горячую клавишу может потребоваться настроить в параметрах клавиатуры GNOME вручную. |

## Быстрый старт за 60 секунд

1. **Запустите MaxLaunchpad.** Появится виртуальная клавиатура, значок приложения также появится в области уведомлений.
2. **Включите `View > Drag & Drop Mode`**, чтобы окно оставалось видимым во время настройки.
3. **Перетащите приложения на клавиши** из Проводника / Finder / файлов — либо щёлкните по клавише правой кнопкой → **Edit** и используйте **Quick Select** для поиска установленных приложений.
4. **Назовите вкладки** (правой кнопкой по цифровой клавише `1`–`0` → Edit), например `Dev`, `Work`, `Games`.
5. **Выключите режим перетаскивания**, нажмите `Alt` + `` ` `` в любом месте, затем нужную клавишу. Готово.

Все пользовательские данные по умолчанию хранятся здесь:

```text
~/.config/MaxLaunchpad/
├── settings.yaml     # Настройки приложения и глобальная горячая клавиша
├── keyboard.yaml     # Профиль клавиатуры по умолчанию
├── caches/           # Кэш значков
├── logs/             # Журналы приложения
├── styles/           # Пользовательские CSS-темы
└── backups/          # Автоматические резервные копии
```

Если задана переменная `XDG_CONFIG_HOME`, пути изменяются соответствующим образом. Поместите эту папку в Git, Dropbox или Syncthing, чтобы синхронизировать настройки лаунчера между компьютерами.

## Раскладка клавиатуры и сочетания клавиш

```text
F1 F2 F3 F4 F5 F6 F7 F8 F9 F10   Общие для всех вкладок сочетания
1  2  3  4  5  6  7  8  9  0     Переключение вкладок
Q  W  E  R  T  Y  U  I  O  P
A  S  D  F  G  H  J  K  L  ;     30 клавиш приложений на вкладку
Z  X  C  V  B  N  M  ,  .  /
```

| Сочетание | Действие |
| --- | --- |
| `Alt` + `` ` `` (в macOS `Option` + `` ` ``) | Показать / скрыть MaxLaunchpad |
| `F1`–`F10` | Запустить глобальное сочетание |
| `Q`–`P`, `A`–`;`, `Z`–`/` | Запустить приложение на активной вкладке |
| `1`–`0` | Перейти на соответствующую вкладку |
| `←` / `→` | Предыдущая / следующая вкладка |
| `Ctrl+F` / `Cmd+F` | Поиск по всем сочетаниям |
| `Esc` | Закрыть диалог или скрыть окно |
| Левый щелчок по клавише | Запустить программу |
| Правый щелчок по клавише | Контекстное меню (Изменить / Копировать / Вырезать / Вставить / Удалить / Открыть расположение файла) |
| Перетащить файл на клавишу | Настроить эту клавишу |

## Пример конфигурации YAML

```yaml
tabs:
  - id: '1'
    label: 'Разработка'
  - id: '2'
    label: 'Работа'

keys:
  - tabId: '1'
    id: Q
    label: Терминал
    filePath: '/Applications/Terminal.app'

  - tabId: '1'
    id: C
    label: Chrome
    filePath: 'https://www.google.com'
```

Для каждого сочетания также можно задать поля `arguments`, `workingDirectory`, `runAsAdmin`, `description` и собственный значок. Полный пример: [`docs/examples/full-featured.yaml`](../examples/full-featured.yaml).

## Частые вопросы

**MaxLaunchpad бесплатен?**  Да. Проект распространяется по лицензии MIT, это бесплатное приложение с открытым исходным кодом.

**Поддерживаются ли Windows 11 и Apple Silicon?**  Да. Windows 11 входит в число поддерживаемых версий «Windows 10+», а установщик для macOS рассчитан на Apple Silicon.

**Работает ли глобальная горячая клавиша в Linux / Wayland?**  Да, но в некоторых средах рабочего стола сочетание нужно привязать вручную в системных настройках клавиатуры.

**Можно ли запускать приложения из Microsoft Store, ярлыки `.lnk` и скрипты?**  Да. Windows: `.exe`, `.lnk`, `.bat`, `.cmd`, `.ps1`, UWP и `shell:`; macOS: `.app`, исполняемые файлы Unix, `.sh`, `.command`; Linux: ELF, `.desktop`, `.sh`, `.py` и `.rb`.

**Где находятся журналы и резервные копии?**  В `~/.config/MaxLaunchpad/logs/` и `~/.config/MaxLaunchpad/backups/`.
